## Approach

Use the existing exact-pane bundled helper connection for both local and gateway-peer computers. A separate SFTP login would duplicate credentials/routing and would not serve the local connection; extending curated document discovery would mix two different uses. Keep curated Markdown/HTML previews in Documents and Kiro in Specs. Add a Files tab with a browsable directory list, parent/breadcrumb navigation, editable absolute location, Home and Session folder actions, hidden-file toggle, filtering and refresh. Show folders before files; file rows show name, size and kind. Show regular Markdown/HTML through the existing restrictive viewer with Back to files; other files show metadata. Files does not execute files, rename/delete resources, download or attach uploads to prompts in this version.

## Host boundary

fs.list/path, fs.read/path/scope/name/revision on discovery; fs.begin/path/scope/name/size/sha256, fs.chunk/token/offset/bytes, fs.finish/token and fs.cancel/token on transfer. Exact route validation at Dart/Swift/Python/gateway, before and after reads and before upload publication. Start path empty means foreground_cwd or cwd of the exact pane, never the helper cwd; ~ means account home. Canonical absolute paths may browse outside the project. Follow explicitly navigated directory symlinks to their canonical destination, open all canonical components with O_NOFOLLOW and hold the directory descriptor for each operation/upload. Reads use no-follow regular files and 256 KiB UTF-8 limit. Uploads use ordinary account write permissions, private staging directories in the destination, sequential acknowledged 256 KiB chunks, SHA-256/size verification and atomic no-replace publication through the host’s native exclusive rename, with a hard-link fallback. Existing names, symlinks and special files cannot be overwritten. Keep held directory identity and route/cwd context; reject replaced locations or changed pane generations.

Bounds: 32 MiB per upload; four pending uploads with 64 MiB aggregate per worker; five-minute expiry; clean partial files on cancel/connection close; no automatic retry of finish after lost acknowledgement. List scans at most 4096 entries and returns up to 1000 within 512 KiB, with an explicit limited label. Reject control/unencodable names, path >4096 UTF-8 bytes, name >255 UTF-8 bytes. Errors stay inside Files; no terminal delivery warning or focus movement. Users can retry explicit actions. Upload progress remains visible and offers cancel. Native file picker on Mac/iPhone and Finder file drops on the Files area; cap selection at 20 and transfer sequentially. No archive extraction or recursive folder upload.

## UI state and focus

Keep existing persisted key 'files' for Documents so old open state remains compatible. New browser key 'browser'; preserve document tabs and session subtree. Pinned list tabs become horizontally scrollable together on narrow panes. Browser only loads when selected, active and visible; no polling over arbitrary directories; manual refresh after upload. Route changes recreate its state, ignore obsolete replies and cancel transfers. Browsing/path editing/preview/upload controls own panel focus, never terminal input. Closing or backgrounding cancels transfers; never redisplay stale data as another folder. Keep browser directory/text in memory only.
